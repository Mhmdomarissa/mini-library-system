# Lexora - Frontend

Next.js 16 (App Router) frontend for the Lexora library management system.
See the root README.md for full project overview, architecture, and deployment docs.

## Run

    cp .env.example .env.local
    npm install
    npm run dev

## Stack

Next.js 16, TypeScript, Tailwind CSS v4, shadcn/ui, TanStack Query v5, React Hook Form + Zod, Firebase, Framer Motion
